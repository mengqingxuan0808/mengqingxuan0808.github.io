高中物理 · 动态平衡的七种常见类型

发表于2026-11-02|更新于2026-11-02|学习

题目里出现「缓慢」「慢慢移动」「缓缓转到」这类词，基本就是在说：每个位置都可以当成静止，合力为零，但各力的大小、方向会随位置变化。这就是动态平衡。

这类题不难，难在「不知道从哪儿下手」。下面按模型分成七类，每类给出识别特征和解法，最后有一套通用流程。

一、先记住三个基本事实

  1. 合力为零：三个力必能首尾相接围成一个闭合三角形（矢量三角形）。
  2. 重力通常是不变量：大小方向都不变，是最可靠的「参照边」。
  3. 判断谁在变：先给每个力标上「方向变 / 大小变 / 都不变」，再决定用哪种方法。

二、七种常见类型

类型 1：图解法（一力恒定 + 一力方向不变）

特征：重力 mg 恒定；某个力（如支持力 N）方向固定、只有大小变；第三个力（如绳的拉力 T）方向在变。

做法：把三个力平移成闭合三角形。mg 那条边不动，方向不变的力只能沿它的作用线伸缩，于是第三个顶点沿着某条直线移动，边长怎么变一目了然。

结论：方向变化的那两个力，夹角越接近 90°，其中一个力越小；当某力与「方向不变的力」垂直时，它取最小值。

典型模型：挡板缓慢转动把球压在墙上；绳绕过定滑轮缓慢拉动物体。

类型 2：相似三角形法

特征：力的三角形和题目里的几何三角形「长得像」——三组边分别平行。

做法：找出对应关系，用比例式把「力」换算成「长度」：

F₁ / L₁ = F₂ / L₂ = mg / L₃

于是「力怎么变」变成「这段线怎么变」，几何直观直接给答案。

典型模型：光滑球面上用绳系住小球、杆靠在墙上、绳跨滑轮两端挂物。

类型 3：辅助圆法（两力夹角不变）

特征：一个力恒定（通常是 mg），另外两个力的夹角保持不变，只是整体在转。

原理：闭合三角形中，mg 对应的边固定，它所对的角（两力夹角）也不变。由圆周角定理，第三个顶点只能在一段圆弧上运动。

结论：顶点在圆上滑动时，某条弦成为直径的瞬间，对应的力最大；两力大小变化可以直接从圆上读出来。

典型模型：一根绳两端固定、中间挂重物缓慢移动悬挂点；两绳夹角恒定的悬挂系统。

类型 4：解析法（列函数求极值）

特征：角度连续变化，问「最小拉力」「力的变化规律」，或要定量关系。

做法：正交分解，写出力与角度的函数关系，再用数学求极值。常见结论：

  • 拉物体沿水平面匀速前进，拉力与水平方向夹角 θ 满足 tanθ = μ 时最省力；
  • 斜面上恰好不下滑 / 不上滑的临界条件是 tanθ = μ。

类型 5：整体法与隔离法

特征：两个及以上物体一起缓慢移动（叠放、通过绳或杆连接）。

做法：

  • 先整体：把系统看作一个物体，求外力（地面支持力、摩擦力），省掉内部相互作用；
  • 再隔离：单独取一个物体，求内力（绳的张力、接触面弹力）。

顺序别反，先整体往往能少列一半方程。

类型 6：临界与极值

特征：出现「刚好」「恰好」「最大」「最小」「绳刚要断」「刚要滑动」。

三类临界条件：

临界类型 条件
接触面刚要分离 N = 0
刚要相对滑动 f = μN（静摩擦取最大值）
绳刚要松弛 / 刚要断 T = 0 / T = T最大

把临界条件代入平衡方程，解出来的就是临界值。

类型 7：力矩平衡（杠杆类）

特征：有固定转轴，力臂随位置变化。

做法：对转轴取力矩，ΣM = 0，写成 F·L_F = G·L_G，再看两边力臂怎么变。杆的自重如果不可忽略，要把它当成作用在重心上的力。

三、一道例题（相似三角形）

题目：光滑半球面半径为 R，小球用细绳系在球面最高点 A，绳长 L。缓慢拉绳使小球沿球面上移（L 逐渐变小），求绳的拉力 T 和支持力 N 如何变化。

受力分析：小球受三个力——重力 mg（竖直向下）、绳的拉力 T（沿绳指向 A）、球面支持力 N（沿半径向外）。三个力平衡，构成闭合三角形。

找相似：设球心为 O。几何三角形 O-A-P（P 为小球位置）三边为 OA = R、OP = R、AP = L；而三个力分别平行于这三条边，所以力三角形与几何三角形相似。

列比例：

T / L = N / R = mg / R

结论：

  • N = mg，支持力保持不变；
  • T = mg·L / R，绳变短时 T 随之减小。

这类题如果硬算角度，会写出一堆三角函数；用相似三角形两三行就完了。

四、通用解题流程

  1. 圈出「缓慢」→ 合力为零；
  2. 画完整受力图，给每个力标注「变 / 不变」；
  3. 三力且有一力恒定 → 先试矢量三角形（图解法）；
  4. 力三角形与几何三角形平行 → 相似三角形法；
  5. 两力夹角不变 → 辅助圆；
  6. 问极值、问角度关系 → 正交分解列函数；
  7. 多物体 → 先整体后隔离；
  8. 出现「刚好 / 恰好」→ 先写临界条件，再代方程。

五、几个容易踩的坑

  • 把「缓慢」当「匀速运动」：缓慢意味着每一刻都平衡，不是让你用运动学公式；
  • 漏掉摩擦力方向的变化：物体有相对运动趋势时，静摩擦方向可能随外力改变而反向；
  • 图解法画错起点：三个力必须首尾相接成闭合三角形，不是都从同一点出发；
  • 相似三角形找错对应边：先确认「哪条力平行于哪条几何边」，再写比例；
  • 临界条件写反：刚要分离是 N = 0，刚要滑动是 f = μN，别混。

动态平衡的题，模型就那么几种，认出来之后剩下的都是画图和比例。建议把上面七类的「特征」抄在一张卡片上，做题前先对号入座。
